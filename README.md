Este projeto em Python foi criado para treinar os comandos novos aprendidos,  estruturas de decis
ão e contadores:
    .for → repetição
    .if/elif/else → decisão
    .contador += 1 → contagem

O programa solicita o **nome da pessoa**, **idade**,e pede para atribuir uma nota  **1,2 ou 3**, sendo **1 Excelente; 2 Bom ; 3 Ruim.** Com essas informações ele consegue reportar a quantidade de votos excelentes e ruins, ignorando os bons.
Sendo assim, o programa consegue apresentar de forma clara e objetiva os resultados da pesquisa de satisfação
